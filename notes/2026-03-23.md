# Discrete Critic Stabilization

## Done

### Stage 2 — statistical significance test

- **Protocol**: top-10 Stage 1 configs × 20 seeds, full 40-epoch training, no pruning
- **Test**: Kruskal-Wallis → pairwise Mann-Whitney U (one-sided, Bonferroni α = 0.05 / 9 comparisons)
- **Result**: KW H = 7.65, **p = 0.5698** — no significant differences between top-10 configs

| Metric | Value |
|---|---|
| Best config median val_r | ~1.05 |
| Best config std (20 seeds) | 0.384 |
| Worst config median val_r | ~0.98 |

**Interpretation**: hyperparameters are not the bottleneck. Std ≈ 0.38 over 20 seeds on a 6-month window signals unconverged policy — the agent is still exploring at evaluation time, not having found a stable strategy. The search space is correctly specified; the problem is elsewhere.

### Literature survey — value-based RL in finance (2023–2025)

**Meta-finding** (ACM Computing Surveys, [arXiv:2408.10932]): no statistically significant difference between value-based and policy-gradient families (p = 0.640). Execution quality and feature engineering matter more than algorithm choice. This is consistent with our Stage 2 null result — we're not in hyperparameter hell, the model hasn't converged.

**Strongest algorithm premium by market type** (same survey): market making (+0.49 Sharpe vs. baseline) and crypto (+0.38), not portfolio optimization. Our discrete 3-action setup is well-suited.

**Distributional RL is the dominant frontier**:
- *"Risk-Averse Policies for Natural Gas Futures Using Distributional RL"* ([arXiv:2501.04421]) — head-to-head C51 vs QR-DQN vs IQN vs DQN on commodity futures. C51 achieves **>32% improvement** over best classical RL. **IQN + CVaR is most stable** under risk-averse objective; QR-DQN shows less predictable behavior under CVaR. Strong evidence to upgrade to IQN head.
- **No papers found using IQN/QR-DQN on crypto hourly data** — genuine research gap; our setup would be a novel contribution.

**Rainbow components that survive financial ablations**:
- Double DQN — near-universal, eliminates overestimation lethal with sparse rewards
- Dueling — consistently helps when flat/hold action dominates (our case)
- N-step (n=3–8) — consistently beneficial for daily/hourly; captures momentum
- PER — mixed; helps for rare large-move events; can hurt in trending regimes where recency > priority

**What doesn't transfer**: Noisy Networks (financial signals already noisy; Markov ε is better); C51 (fixed support requires knowing return scale).

**Non-stationarity**: unsolved. Main approaches: rolling-window buffer, wavelet decomposition (DWT on price → CMR-DQN 2024 achieved +20–55% on equities), regime-conditioned Q. ARF-style continual RL is an emerging direction.

**Benchmark numbers**:

| Paper                                     | Method              | Asset       | Sharpe                      |
| ----------------------------------------- | ------------------- | ----------- | --------------------------- |
| M-DQN (Sci. Reports 2024)                 | DQN + sentiment     | BTC         | **2.74** (favorable window) |
| FinRL 2024 best team ([arXiv:2504.02281]) | DQN ensemble        | BTC LOB     | **1.08**                    |
| FinRL 2024 DDQN/Dueling ensemble          | Ensemble            | BTC LOB     | 0.28                        |
| CMR-DQN (MDPI 2024)                       | Rainbow + DWT + TCN | 6 stocks    | 0.73                        |
| Survey meta-analysis                      | Hybrid DQN avg      | Multi-asset | **1.57** avg                |

Realistic hourly crypto target: Sharpe **0.5–1.2** in proper walk-forward. Sharpe >2 in papers almost always reflects narrow/bull-period test windows.

**Our differentiator**: Markov ε-exploration + Bellman switching cost has no direct comparator in literature. Positioning: Rainbow + IQN/CVaR + switching cost + structured exploration would be a novel combination.

## Possible ToDos

### Priority 1 — Environment extensions (targets convergence + non-stationarity)

- [ ] **Staircase parallelization** — replace random env starts with fixed offsets (stride = `total_len / n_envs`, e.g. 1k for 13k/13 envs); envs cycle in rings. Goal: at each training step, the replay buffer spans the full training distribution; temporal curriculum via shared weights (env k+1 benefits from env k's learned policy before entering the same period). Start with stride=1k (no overlap), try 500 if convergence is still slow.
- [ ] **Action encoding mode** — extend environment class with a `action_mode` parameter; support at minimum: `target_position` (current, 3 actions: flat/long/short) and `delta` (3 actions: move_up/stay/move_down, environment applies delta and clamps). Delta mode: cleaner switching cost semantics (`action != stay`), natural Markov exploration, no implicit stay ambiguity. 5-action explicit open/close deferred (invalid action masking complexity).
